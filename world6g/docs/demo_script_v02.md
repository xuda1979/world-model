## 冻结数字 (2026-11-12, 复现命令)

- 默认回放切片: campus·seed9000·ep0, 10 tick, 整段回报 Σreward = **4.7318**; 高光步 tick8 (p=(0,+3,-6)) reward = +3.065 (正收益示例)
- 场景累计回报 (全部 180 ep): 城区 +386.6, 郊区 +326.5, 机器人工厂 +174.0, campus +141.3, 低空 −164.6 (低空为负 — 演示"不是所有场景都该上协同")
- 协同策略: CoordPolicyNet 61.4 万参数双头 MLP (params=613,874), 动作空间 3 小区 × 5 档 = 125 组合; LOSO 相对 oracle 已实现增益率 **0.9631**, 精确命中率 60%, 平均 regret 0.128
- 天花板探针 (`wm_ceiling_probe.json`): v3 特征 → win_obj[t+1] R²=**0.8978**; ref_obj[t+1] R²=0.8982 (纯外生, 几乎充满); reward R²=0.6211 (上限 oracle 0.6459); **v2 NN 基线 0.5337 → 天花板 0.62** — "还有 ~0.09 空间, 不值得再烧调参, 改特征/结构才值得"

## 退出/异常预案

- 时序数据缺失 → 面板显示"时序回放不可用", 脚本跳到问答+导出环节 (不阻塞验收)
- 模型权重缺失 → 协同策略面板返回"推理中…→ 调用失败"; 预演前运行训练脚本, 演示机建议带 `.pt` 权重
- 演示机无外网 → 问答为本地规则引擎, 3D 用 Plotly 本地渲染, 数据全在 parquet — 全流程离线可用
