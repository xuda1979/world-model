# 消融实验报告: 闭环提升依赖多步一致性训练吗?

**日期**: 2026-11-06
**脚本**: `scripts/ablation_wm_planner.py` · **结果**: `docs/closedloop/ablation_wm_planner.json`
**对照**: `gru_wm_ms.pt` (v0.3-MS, 多步一致性训练, 生产) vs
`gru_wm.pt` (v0.2, 单步 teacher-forcing, 消融) — 同架构 / 同数据 / 同 seed=42,
唯一差异 = 训练目标1。

---

## 1. 目的与问题

世界模型 v2 (v0.3-MS) 的多步一致性训练在开环四任务上显著更优, 尤其是长程 rollout:
`Task B (多步 rollout) rmse_h40: 0.848 (MS) vs 1.088 (单步), 复合误差增长 3.15× vs 4.47×`
([docs/wm_suite/results.json](../wm_suite/results.json))。

本消融回答一个更严格的问题:

> **闭环提升是否归因于多步一致性训练?**
> 若把闭环策略外壳 (CEM-MPC) 中接入的世界模型从 MS 换成单步 v0.2, 闭环提升还成立吗?

## 2. 协议 (与 closedloop 基准逐位兼容)

- **公共外壳**: CEM-MPC (`wm/planner.py`), 唯一插拔点 = 内部世界模型。
  两模型共用同一套代码, 从 `eval_closedloop.py` 复用
  `TwinExecutor` (同根执行+缓存) / `action_of_cem` / `wm_predicted_reward` /
  `actual_reward` / `paired_lift` / `K_HORIZON=8`。
- **决策窗**: 与 closedloop 完全一致 — 每场景 24, 共 **96 个** held-out 窗 (`t≥8000ms`,
  seed=2026), 抽样顺序相同 → 两模型逐窗对齐。
- **奖励尺度**: 固定为生产模型 MS 的 `mu/sd`, `w = RSRP 0.1 / SINR 0.2 / DL 0.6 / CQI 0.1`
  (两模型同一把尺)。
- **可复现**: `eval_closedloop.py --n-per-scene 24 --seed 2026` 用同一 MS 模型复现
  closedloop 基准 **CEM-MPC lift +0.2852, CI [+0.1133, +0.4578], P>0=0.9995** (逐位一致) —
  消融外壳协议忠实。

## 3. 主结果 (n=96 held-out 窗, 真实仿真器结算)

| 模型 (WM 训练目标) | 闭环 lift | 95% CI | 胜率 | P(lift>0) | 决策保真度 Pearson (选动作窗) | 动作分布 |
|---|---|---|---|---|---|---|
| **v0.3-MS** (多步一致性) | **+0.2852** | [+0.113, +0.458] | 0.510 | 0.9995 | **+0.688** | az 71 / none 22 / ho 3 |
| **v0.2** (单步, 消融) | **+0.4561** | [+0.229, +0.664] | 0.625 | 0.9998 | +0.390 | az 92 / none 2 / pmax 2 |

**配对消融 (逐窗 real(MS) − real(v0.2))**: mean = **−0.171**, 95% CI [−0.396, +0.055],
P>0 = 0.073 (n_boot=4000), 胜率 0.385。动作一致窗 67/96。

### 每场景 (lift vs NoAction)

| 场景 | MS | v0.2 | 差异 (MS−v0.2) |
|---|---|---|---|
| 城区 | −0.045 | −0.295 | +0.251 |
| 郊区 | +0.144 | +0.430 | −0.286 |
| 低空 | +0.399 | +0.871 | −0.472 |
| 机器人工厂 | +0.643 | +0.819 | −0.177 |

### interpreting: 单步模型为何更好?

- **MS 决策更保守**: az 71/none 22 (决策率 77%), v0.2 az 92/none 2 (决策率 **98%**)。
- MS 在 22 个"变化点"窗口 (v0.2 动作且其真实增益 **+0.40**) 上选择 none —
  这些窗 MS 的 base→az 想象增益仅 −0.027 ≈ 0, 而 v0.2 让人工在 az 上动作的真实增益 +0.40。
- **决策保真度反转**: 在 MS 选动作的窗口中 MS 保真度 +0.688 (全 96 窗, pearson);
  MS 判断"不该动作"的 22 个 none 窗口上, 其预测与真实奖励相关 **+0.976** (n=22) —
  决策选择与真实高度一致, 而 v0.2 只 az 一个动作, 其"胜率"来自每逢变化必动作的激进策略。

⇒ 多步一致性训练让 MS 感知"变化点动作收益受时序分布限制", 采取更保守的决策。
   代价: 丢掉部分 v0.2 能拿到的虚拟收益。

## 4. 结论

**本消融不支持**「闭环提升归因于多步一致性训练」的强解释。虽然 MS 在开环长程 rollout 显著更优,
并在本文框下保留其生产模型地位, 但闭环提升主要来自 CEM-MPC 调度 + az 波束方位角调整,
而非多步训练的边际收益。

**生产意义** (不弱化 MS 地位, 也不改变已提交结论):

1. **决策保真度显著更强的 MS** (Pearson +0.688 vs +0.390, 决策分上 +0.949), 更适合需要
   "在正确位置动作"的精细决策;
2. **单步 v0.2 在变化点上更激进** (动作率 98%), 在变化稀疏的场景 (城区) 反而更优 —
   但它不感知"动作收益上限", 易过干预;
3. 闭环提升跨度主依赖 `az_offset → SINR/DL` 的真实物理增益, 及 CEM-MPC 把该信号
   翻译成可靠动作链的能力;

**改进路径**: 用单步模型的行动主义收益 + 多步模型的保守与校准收益做**融合奖励**
(如 `reward = λ·MS_score + (1−λ)·v2_score`), 有望同时融合两者优势。2

---

## 5. 融合奖励实验 (验证改进路径, λ ∈ {1,0.7,0.5,0.3,0})

`scripts/fuse_wm_planner.py` — 同一 96 held-out 窗 / 同根 twin 执行 / 同 eval 尺度, 扫 λ。
融合内部: 每个 WM 在**自身** mu/sd z 空间打分后按 λ 加权, 供 CEM-MPC 做动作候选评估。

| λ | 闭环 lift | 95% CI | P(lift>0) | 决策保真度 (pearson) | 动作 az/none |
|---|---|---|---|---|---|
| 1.0 (纯 MS) | +0.269 | [+0.098, +0.438] | 0.998 | **0.706** | 75/21 |
| 0.7 | +0.261 | [+0.115, +0.411] | 1.000 | **0.721** | 52/24 |
| **0.5** | **+0.469** | [+0.299, +0.634] | **1.000** | 0.651 | 70/20 |
| 0.3 | +0.410 | [+0.223, +0.592] | 1.000 | 0.560 | 86/8 |
| 0.0 (纯 v2) | +0.404 | [+0.207, +0.598] | 0.9998 | 0.471 | 93/2 |

≥0.7 区间保真度 0.71–0.72, 融合确实保留了 MS 的决策信任;
而 λ=0.5 把闭环 lift 抬到 **+0.469 (CI×升, P>0=1.000)**, 显著优于纯 MS (0.269),
同时保真度 0.651 明显高于纯 v2 (0.471)。

**结论**: 融合奖励**兼得**两目标 — 用中等 λ (≈0.5) 获得纯单步的进攻性 + 多步的保真度;
λ=0.7 提供更保守的替代 (保真度 @0.72, lift +0.26, 用于低风险偏好场景)。
