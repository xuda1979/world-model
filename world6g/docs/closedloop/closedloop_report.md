# 闭环评测报告 (Closed-Loop Evaluation Report)

**日期**: 2026-11-06
**脚本**: `scripts/eval_closedloop.py` · **结果**: `docs/closedloop/closedloop_results.json`
**模型**: `models/gru_wm_ms.pt` (世界模型 v2, 多步一致性训练) + `models/policy_net.pt` (动作模型/策略) + CEM-MPC (`wm/planner.py`)

---

## 1. 目的与协议

此前的评测仅在世界模型 (WM) 内部计算奖励——即"模型说好就是好"。闭环评测补上关键一环:
**把各策略推荐的动作真实施加到仿真器 (TinyTwin 同根分支), 用真实 KPI 轨迹结算奖励**, 对比四种策略:

| 策略 | 说明 |
|---|---|
| **CEM-MPC** | 基于 WM 的交叉熵方法模型预测控制 (`wm/planner.py`), horizon=8 步 |
| **Policy** | 训练好的动作模型/策略网络 (`models/policy_net.pt`) |
| **Random** | 动作空间均匀随机 (阴性对照) |
| **NoAction** | 不施加任何动作 (零基线) |

**协议细节** (与反事实数据生成 `generate_actions.py` 完全同根):

1. **同根校验**: 评测前把数据集 baseline 与现场 twin 重跑逐场景逐 UE 比对,
   `4 场景 × 8 UE 全部一致` (twin 确定性 + 数据集种子对齐), 见 `meta.same_root_verified: true`。
2. **决策窗**: 每场景 24 个 (共 **96 个** held-out 窗), 仅取 held-out 段 `t ≥ 8000ms`,
   种子 2026, 在 8 UE × 时间轴上分层采样, 排除重叠窗。
3. **奖励结算**: 动作施加后, 取 horizon=8 步 (400ms) 的真实状态轨迹 `s[lo:hi]`,
   归一化后按权重 `RSRP 0.1 / SINR 0.2 / DL 0.6 / CQI 0.1` 加权求和取时间平均 (与训练奖励同构)。
4. **lift 定义**: `lift = R(策略) − R(NoAction)`, 同一 (场景, UE, t) 窗配对; bootstrap 95% CI (n_boot=10000)。
5. **WM 保真度**: 每个决策同时记录 WM 预测奖励与真实奖励, 报告 Pearson/Spearman 相关与平均绝对差。

## 2. 主结果 (n=96 held-out 窗, 真实仿真器结算)

| 策略 | 真实奖励 | 动作率 | lift 均值 | 95% CI | 胜率 | P(lift>0) |
|---|---|---|---|---|---|---|
| **CEM-MPC** | **−0.147** | 0.77 | **+0.285** | [+0.113, +0.458] | 0.51 | **0.9995** |
| **Policy** | **−0.149** | 0.79 | **+0.283** | [+0.106, +0.459] | 0.55 | **0.9988** |
| Random | −0.442 | 1.00 | −0.010 | [−0.103, +0.089] | 0.44 | 0.407 |
| NoAction | −0.432 | 0.00 | 0 (基准) | — | — | — |

**三个关键结论**:

1. **CEM-MPC 与 Policy 在真实仿真器上显著优于 NoAction** — lift 95% CI 完全位于 0 以上
   (P>0 分别为 0.9995 / 0.9988), 平均提升约 **+0.28** 个归一化奖励单位。
   这说明 WM 推荐的动作不仅在模型内"自认为好", 在真实仿真器动态下同样有效。
2. **Random 阴性对照如预期无效** (lift ≈ 0, P>0=0.41, CI 跨 0) — 排除了"随便动一动就好"的解释,
   提升确实来自 WM/策略的决策质量。
3. **CEM-MPC ≈ Policy** (lift 0.285 vs 0.283): 在线规划与离线策略网络效果相当,
   说明策略网络已蒸馏出规划器的决策能力, 推理成本可大幅降低 (单次前向 vs CEM 迭代采样)。

### 每场景细分 (lift vs NoAction, P>0 为 bootstrap 概率)

| 场景 | CEM-MPC | Policy | Random |
|---|---|---|---|
| 城区 | +0.066 | −0.015 | −0.069 |
| 郊区 | +0.161 | +0.162 | −0.020 |
| 低空 | +0.399 | +0.293 | +0.061 |
| 机器人工厂 | **+0.643** | **+0.717** | +0.035 |

- **机器人工厂**提升最大且 CI 严格为正 (P>0 = 1.000) — 该场景动作敏感度最高。
- **低空**提升明显 (CEM-MPC P>0=0.955)。
- **城区**基线已较好, 提升空间有限; 各策略在该场景差异不显著。

### 动作分布 (96 窗)

| 策略 | az_offset | none | ho_offset | prb_scale | pmax_scale |
|---|---|---|---|---|---|
| CEM-MPC | 71 | 22 | 3 | 0 | 0 |
| Policy | 76 | 20 | 0 | 0 | 0 |
| Random | 28 | 0 | 22 | 23 | 23 |

两个学习型策略高度一致地选择 **az_offset (波束方位角调整)** 作为主要动作 — 与直觉相符:
调整波束指向是提升 SINR/DL 最直接的手段。当几何条件已接近最优时选择 `none` (约 21–23%),
体现了"不过度干预"的判断。

## 3. WM 决策保真度 (预测 vs 真实)

| 指标 | 值 |
|---|---|
| Pearson r | **+0.798** |
| Spearman r | **+0.782** |
| mean abs gap | 0.468 |
| n (决策对) | 384 |

WM 预测奖励与真实结算奖励的秩相关 **Spearman +0.78** — 模型对"哪个动作更好"的排序能力
(这正是决策所需的) 显著强于对绝对值的回归 (Pearson 存在系统尺度差, mean gap 0.47)。
这与世界模型 v2 的多步一致性训练目标一致: 优化排序/方向正确性优先于绝对幅度。
